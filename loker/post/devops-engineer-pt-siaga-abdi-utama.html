DevOps Engineer (Entry-Level/Junior)

🏢 PT Siaga Abdi Utama 📍 Jakarta 💼 Full-time 💰 Rp 8-15 Juta 📅 2026-07-02
Full-time Teknologi

PT Siaga Abdi Utama, perusahaan solusi teknologi dan layanan IT terpercaya, mencari DevOps Engineer entry-level/junior untuk bergabung dengan tim infrastructure mereka di Jakarta. Posisi ini cocok untuk fresh graduate atau junior engineer yang ingin mengembangkan karir di bidang cloud infrastructure, CI/CD pipeline, dan automation. Kandidat akan belajar mengelola lingkungan production, membangun pipeline deployment, dan memastikan reliability sistem bersama senior engineer.

📎 Sumber: LinkedIn

Kualifikasi

  • Fresh graduate S1 Ilmu Komputer/Teknik Informatika atau setara (max 2 tahun pengalaman)
  • Paham konsep Linux/Unix, networking dasar (DNS, HTTP, TCP/IP, firewall)
  • Menguasai minimal satu cloud provider: AWS, GCP, atau Azure
  • Familiar dengan containerization: Docker dan Kubernetes (minimal konsep)
  • Paham CI/CD tools: GitLab CI, GitHub Actions, Jenkins, atau ArgoCD
  • Scripting dasar: Bash, Python, atau Go untuk automation
  • Paham Infrastructure as Code: Terraform atau Ansible (nilai plus)
  • Bersedia on-site di Jakarta dan on-call rotation

Tanggung Jawab

  • Membantu maintenance dan monitoring infrastructure cloud (AWS/GCP/Azure)
  • Membangun dan maintain CI/CD pipeline untuk aplikasi microservices
  • Mengelola Kubernetes cluster: deployment, scaling, troubleshooting
  • Membuat script automation untuk provisioning dan operasi rutin
  • Melakukan log analysis dan incident response bersama tim
  • Mendokumentasikan runbook dan SOP infrastruktur
  • Berpartisipasi dalam code review untuk infrastructure-as-code
  • Belajar dan implementasi best practice security & compliance

Benefit

  • Gaji entry-level kompetitif + bonus performa
  • Program mentoring intensif dari Senior DevOps Engineer
  • Budget sertifikasi cloud (AWS/Azure/GCP) dan training teknis
  • BPJS Ketenagakerjaan & Kesehatan + asuransi tambahan
  • MacBook Pro / workstation high-spec untuk development
  • Flexible working hours & hybrid arrangement (setelah probation)
  • Akses ke komunitas tech internal & external event
