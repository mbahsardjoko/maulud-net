Full-time Teknologi

FIT HUB, startup health and wellness berbasis teknologi yang berbasis di Jakarta, mencari Data Engineer untuk bergabung dengan tim data mereka. Sebagai Data Engineer di FIT HUB, kamu akan membangun dan memelihara infrastruktur data yang mendukung analisis bisnis, pengambilan keputusan, dan pengembangan produk. Kamu akan bekerja dengan volume data besar dari berbagai sumber — mulai dari transaksi member, data latihan, hingga data operasional klub. Posisi ini cocok untuk data engineer yang ingin menerapkan keahliannya di industri kebugaran dan kesehatan yang berkembang pesat di Indonesia.

Kualifikasi

  • Pengalaman minimal 2 tahun sebagai Data Engineer atau peran serupa
  • Mahir dalam SQL dan database relasional (PostgreSQL, MySQL)
  • Pengalaman dengan data warehouse (BigQuery, Snowflake, atau Redshift)
  • Mahir Python untuk data processing (pandas, numpy, PySpark)
  • Pengalaman dengan ETL/ELT pipeline dan workflow orchestration (Airflow, Dagster)
  • Familiar dengan cloud data services (GCP, AWS)
  • Memahami konsep data modeling dan data governance

  • Mengelola data warehouse dan memastikan data quality & consistency
  • Mengembangkan dan mengoptimalkan ETL processes untuk reporting dan analytics
  • Berkolaborasi dengan Data Analyst dan Product team untuk kebutuhan data
  • Memonitor dan menjaga performa pipeline data
  • Mendokumentasikan arsitektur data dan pipeline
