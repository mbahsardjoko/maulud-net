Contract Desain

ZÉRA, studio produk digital, mencari UI/UX Designer kreatif dan detail-oriented untuk bergabung dalam pengembangan produk digital berbasis project. Posisi ini bersifat Project Based (Remote) dengan peluang kerja sama jangka panjang bagi kandidat yang memiliki performa baik. Kamu akan merancang user experience dan interface untuk berbagai klien mulai dari startup hingga enterprise, dengan fokus pada problem solving dan design thinking.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2 tahun pengalaman UI/UX Designer atau Product Designer
  • Portfolio kuat menunjukkan design process: research, wireframe, prototype, testing
  • Mahir Figma (auto-layout, variants, design tokens, prototyping advanced)
  • Paham user research, usability testing, dan design iteration berdasarkan data
  • Memahami design systems, component-based design, dan handoff ke developer
  • Familiar dengan aksesibilitas (WCAG) dan responsive design mobile-first
  • Kemampuan komunikasi untuk presentasi design ke stakeholder non-designer
  • Self-managed, bisa kerja remote dengan komunikasi async yang efektif
  • Bisa kerja project-based remote dari mana saja di Indonesia

Tanggung Jawab

  • Merancang UI/UX untuk berbagai project digital klien (web & mobile)
  • Melakukan user research, competitor analysis, dan design discovery
  • Membuat wireframes, user flows, interactive prototypes di Figma
  • Berkolaborasi dengan developer untuk design handoff & implementation review
  • Membangun dan maintain design system untuk konsistensi multi-project
  • Melakukan usability testing dan iterasi berdasarkan feedback user
  • Menyajikan design rationale dan decision ke klien/stakeholder
  • Mendokumentasikan design process, decisions, dan style guides

Benefit

  • Fleksibilitas jam kerja sepenuhnya (async-first)

  • Portfolio yang beragam untuk pengembangan karier
  • Tim kecil, kolaboratif, minimal birokrasi
  • Peluang kontrak panjang / full-time berdasarkan performa
  • Budget tools: Figma Pro, testing tools, design resources
