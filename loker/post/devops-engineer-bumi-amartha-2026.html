DevOps Engineer

🏢 Bumi Amartha Teknologi Mandiri 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 12-20 Juta 📅 2026-09-05
Full-time Teknologi

Bumi Amartha Teknologi Mandiri, perusahaan teknologi yang fokus pada solusi digital untuk sektor properti dan konstruksi, membuka lowongan DevOps Engineer. Kandidat akan bertanggung jawab atas infrastruktur cloud, CI/CD pipeline, dan reliability sistem yang mendukung platform properti digital mereka. Kesempatan untuk membangun infrastructure from scratch dengan tech stack modern.

📎 Sumber: LinkedIn Indonesia

Kualifikasi

  • Minimal 2-3 tahun pengalaman DevOps/SRE
  • Mahir Kubernetes (EKS/GKE/AKS) dan container orchestration
  • Pengalaman Infrastructure as Code (Terraform, Helm, Ansible)
  • Mahir CI/CD tools (GitLab CI, Jenkins, ArgoCD, GitHub Actions)
  • Paham monitoring stack (Prometheus, Grafana, ELK, Datadog)
  • Kuasai scripting (Python, Bash, Go)
  • Pengalaman cloud provider (AWS/GCP/Azure) - AWS diutamakan
  • Sertifikasi CKAD, CKA, atau AWS DevOps Pro adalah plus

Tanggung Jawab

  • Mendesain dan mengelola Kubernetes cluster production
  • Membangun dan maintain CI/CD pipeline untuk microservices
  • Implementasi Infrastructure as Code dengan Terraform
  • Setup monitoring, alerting, dan log aggregation
  • Optimasi cloud cost dan resource utilization
  • Berkolaborasi dengan dev team untuk deployment strategy
  • Incident response dan troubleshooting infrastruktur
  • Dokumentasi runbook dan disaster recovery plan

Benefit

  • Gaji kompetitif Rp 12-20 Juta
  • BPJS Kesehatan dan Ketenagakerjaan penuh
  • THR, bonus performa, dan tahunan
  • Laptop high-spec disediakan
  • Budget sertifikasi cloud (AWS/Azure/GCP)
  • Fleksibel WFO/WFH hybrid
  • Akses ke training platform (Linux Foundation, Cloud Guru)
  • Proyek property-tech skala nasional
