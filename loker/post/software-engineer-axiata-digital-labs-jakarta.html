Software Engineer

🏢 Axiata Digital Labs 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 15-25 Juta 📅 2026-07-18
Full-time Teknologi

Axiata Digital Labs (ADL), anak perusahaan digital dari Axiata Group (pemilik XL Axiata), mencari Software Engineer untuk bergabung dengan tim engineering di Jakarta. ADL membangun platform digital, solusi enterprise, dan produk inovatif untuk telco dan industri lain di Asia Tenggara. Kamu akan bekerja pada proyek-proyek skala besar dengan tech stack modern, berkolaborasi dengan tim lintas negara, dan memiliki dampak nyata pada jutaan pelanggan.

📎 Sumber: LinkedIn Indonesia

Kualifikasi

  • Pengalaman minimal 3-5 tahun sebagai Software Engineer / Backend Developer
  • Mahir minimal satu bahasa: Java (Spring Boot), Go, Node.js, atau Python
  • Pengalaman solid dengan microservices architecture dan distributed systems
  • Paham database: PostgreSQL, MongoDB, Redis, dan message queue (Kafka/RabbitMQ)
  • Pengalaman dengan container orchestration: Docker, Kubernetes (EKS/GKE/AKS)
  • Familiar dengan cloud platform (AWS/GCP/Azure) dan IaC (Terraform)
  • Kuat di system design, API design (REST/gRPC), dan observability (logging, metrics, tracing)
  • Bahasa Inggris aktif (lisan & tulisan) untuk kolaborasi cross-border
  • Bersedia hybrid di Jakarta dengan occasional travel ke regional office

Tanggung Jawab

  • Merancang, mengembangkan, dan memelihara layanan backend scalable untuk produk ADL
  • Menerapkan clean architecture, design patterns, dan best practices engineering
  • Menulis technical spec, design doc, dan mengikuti architecture review
  • Mengoptimalkan performa sistem: latency, throughput, resource utilization
  • Membangun CI/CD pipeline, automated testing, dan deployment strategies
  • Berkolaborasi dengan Product Manager, QA, DevOps, dan stakeholder bisnis
  • Mentoring junior engineer dan promote engineering excellence
  • On-call rotation untuk production support dan incident response
