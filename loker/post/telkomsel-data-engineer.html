Data Engineer

Full-time Teknologi

Telkomsel, operator telekomunikasi seluler terbesar di Indonesia, membuka lowongan Data Engineer untuk memperkuat tim data mereka. Kamu akan merancang dan membangun pipeline data yang scalable untuk mendukung analitik, machine learning, dan business intelligence di skala jutaan pelanggan. Posisi ini menawarkan tantangan teknis menarik pada data volume besar dengan stack modern cloud-native.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 3 tahun pengalaman sebagai Data Engineer atau ETL Developer
  • Mahir Python untuk data engineering (pandas, PySpark, Airflow)
  • Pengalaman kuat dengan SQL dan database (PostgreSQL, BigQuery, Snowflake)
  • Familiar dengan cloud platform (GCP, AWS, atau Azure) dan managed services
  • Pengalaman dengan tools orchestration: Apache Airflow, Dagster, atau Prefect
  • Paham konsep data warehouse, data lake, dan lakehouse architecture
  • Pengalaman dengan streaming data (Kafka, Flink, atau Kinesis) menjadi nilai tambah
  • Bersedia bekerja on-site/hybrid di Jakarta

Tanggung Jawab

  • Merancang dan membangun end-to-end data pipeline (ingestion, transformation, serving)
  • Mengoptimasi performa query dan pipeline untuk skala petabyte
  • Membangun dan memelihara data warehouse / lakehouse di cloud
  • Berkolaborasi dengan Data Scientist dan Analyst untuk kebutuhan data
  • Menerapkan data quality checks, monitoring, dan alerting
  • Mengelola infrastructure as code untuk data platform (Terraform)
  • Mendokumentasikan data lineage, schema, dan data dictionary
  • Melakukan code review dan best practices data engineering
