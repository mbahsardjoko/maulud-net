Full Stack Developer (Project Based)

🏢 CarbonEthics 📍 Jakarta 💼 Contract 💰 Rp 10-20 Juta 📅 2026-07-11
Contract Teknologi

CarbonEthics, organisasi yang berfokus pada solusi perubahan iklim dan karbon offset berbasis alam di Indonesia, mencari Full Stack Developer untuk mengerjakan proyek berbasis kontrak. Kamu akan mengembangkan platform digital yang memungkinkan individu dan perusahaan menghitung, melacak, dan mengimbangi jejak karbon mereka. Posisi ini menuntut kemampuan full stack yang solid, mulai dari frontend React/Next.js hingga backend Node.js/Python dan database. Ini adalah peluang bagus untuk menggunakan keahlian codingmu untuk dampak lingkungan yang positif.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3 tahun sebagai Full Stack Developer
  • Mahir dalam frontend: React.js, Next.js, atau Vue.js
  • Mahir dalam backend: Node.js, Python (Django/FastAPI) atau Go
  • Pengalaman dengan database relasional (PostgreSQL, MySQL) dan NoSQL (MongoDB)
  • Familiar dengan RESTful API dan GraphQL
  • Pengalaman dengan cloud services (AWS/GCP) dan deployment
  • Memahami prinsip desain responsif dan user experience

  • Mengoptimalkan performa aplikasi dan database

  • Melakukan code review dan menjaga kualitas kode
  • Mendokumentasikan arsitektur dan API untuk tim

Benefit

  • Portofolio proyek berdampak sosial dan lingkungan
