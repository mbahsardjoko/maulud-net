Cloud Engineer

🏢 Code.id 📍 Jakarta Selatan 💼 Kontrak 💰 Dibahas saat interview 📅 07 Juni 2026
Kontrak Teknologi

Code.id mencari Cloud Engineer handal yang berpengalaman dalam infrastruktur cloud dan DevOps. Posisi ini bertanggung jawab untuk mengelola dan mengoptimalkan infrastruktur cloud di AWS, Azure, atau GCP. Kamu akan menerapkan Infrastructure as Code (IaC) menggunakan Terraform, membangun pipeline CI/CD, mengelola container dengan Docker dan Kubernetes, serta memastikan keamanan dan performa lingkungan cloud. Cocok untuk kamu yang suka tantangan teknis dan ingin terus belajar teknologi cloud terbaru.

📎 Sumber: Kalibrr

Kualifikasi

  • Minimal S1 di bidang Ilmu Komputer, Teknologi Informasi, atau bidang terkait
  • Pengalaman 3+ tahun di Cloud Engineering, DevOps, atau Infrastructure
  • Pengalaman hands-on dengan AWS, Azure, atau Google Cloud Platform
  • Mahir menggunakan Terraform atau tools IaC lainnya
  • Pengetahuan tentang Docker dan Kubernetes
  • Pengalaman dengan CI/CD tools seperti Jenkins, GitHub Actions, GitLab CI/CD, atau Azure DevOps
  • Kemampuan scripting dasar (Python, Bash, atau PowerShell)
  • Memahami networking, security, dan arsitektur cloud
  • Kemampuan komunikasi dan dokumentasi yang baik

Tanggung Jawab

  • Mendeploy dan mengelola infrastruktur cloud di AWS, Azure, atau GCP
  • Memantau dan memelihara lingkungan cloud untuk memastikan ketersediaan dan performa
  • Mengimplementasikan Infrastructure as Code (IaC) menggunakan Terraform atau tools serupa
  • Membangun dan mendukung pipeline CI/CD
  • Mengelola aplikasi containerized menggunakan Docker dan Kubernetes
  • Melakukan troubleshooting issue infrastruktur dan deployment
  • Menerapkan best practices keamanan cloud
  • Berkolaborasi dengan tim developer dan stakeholder klien
  • Menyusun dokumentasi teknis dan panduan

Benefit

  • Bekerja dengan teknologi cloud terbaru dan terkini
  • Lingkungan kerja yang mendukung pembelajaran dan sertifikasi
  • Tim teknis yang solid dan kolaboratif
  • Kesempatan mengerjakan project dengan klien dari berbagai industri
  • Pengembangan karir di bidang cloud computing
