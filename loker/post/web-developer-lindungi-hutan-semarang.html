Full-time Teknologi

Lindungi Hutan, startup sosial yang fokus pada konservasi lingkungan dan penghijauan melalui platform digital, membuka lowongan Web Developer di Semarang. Kamu akan bertanggung jawab mengembangkan dan memelihara website perusahaan serta platform digital yang mendukung misi pelestarian lingkungan. Posisi ini menawarkan kesempatan unik untuk menggabungkan skill teknis dengan dampak sosial yang nyata, bekerja dengan tim kecil namun bersemangat yang peduli terhadap masa depan bumi.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 1-3 tahun pengalaman sebagai Web Developer
  • Mahir dalam HTML5, CSS3, JavaScript (ES6+)
  • Pengalaman dengan framework PHP (Laravel/CodeIgniter) atau Node.js
  • Paham database MySQL/PostgreSQL
  • Familiar dengan Git dan version control
  • Pengalaman dengan CMS (WordPress) adalah nilai plus
  • Kemampuan bekerja mandiri dan dalam tim
  • Bersedia bekerja di Semarang (dengan opsi remote terbatas)

Tanggung Jawab

  • Mengembangkan dan memelihara website utama Lindungi Hutan
  • Membangun fitur-fitur baru untuk platform donasi dan kampanye lingkungan
  • Mengoptimalkan performa website dan SEO
  • Berkolaborasi dengan tim konten dan desain untuk pengembangan halaman
  • Melakukan maintenance, update keamanan, dan backup sistem
  • Mengintegrasikan payment gateway dan API pihak ketiga
  • Mendokumentasikan kode dan alur sistem

Benefit

  • Fleksibilitas jam kerja
  • Kesempatan kerja sambil berkontribusi untuk bumi
  • Pengembangan skill dan pelatihan
  • Tim yang kolaboratif dan supportive
