UI/UX Designer

🏢 PT Code Development Indonesia 📍 Jakarta 💼 Full-time 💰 Rp 10-18 Juta 📅 2026-07-03
Full-time Desain

PT Code Development Indonesia mencari UI/UX Designer berpengalaman 3-5 tahun untuk merancang pengalaman pengguna yang intuitif dan menarik. Kamu akan terlibat dari fase riset, wireframing, prototyping, hingga usability testing. Posisi ini membutuhkan kemampuan analisis kebutuhan pengguna dan menterjemahkannya ke dalam desain visual yang fungsional.

📎 Sumber: Glints

Kualifikasi

  • Pengalaman 3-5 tahun sebagai UI/UX Designer
  • Menguasai Figma, Sketch, atau Adobe XD
  • Portfolio yang menunjukkan proses design thinking
  • Paham user research, wireframing, prototyping
  • Memahami design system dan component library
  • Kemampuan komunikasi desain ke stakeholder non-teknis

Tanggung Jawab

  • Melakukan user research dan analisis kebutuhan
  • Membuat wireframe, mockup, dan prototype interaktif
  • Merancang design system dan UI component library
  • Melakukan usability testing dan iterasi desain
  • Berkolaborasi dengan developer untuk implementasi desain
  • Mendokumentasikan keputusan desain dan style guide

Benefit

  • Gaji kompetitif + bonus performa
  • BPJS Ketenagakerjaan dan Kesehatan
  • Remote work option (hybrid)
  • Budget kursus dan konferensi desain
  • MacBook Pro disediakan
  • Tim desain yang kolaboratif
