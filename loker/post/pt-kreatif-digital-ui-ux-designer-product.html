UI/UX Designer (Product)

🏢 PT Kreatif Digital Indonesia 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 8-13 Juta 📅 2026-09-02
Full-time Desain

PT Kreatif Digital Indonesia, agensi kreatif digital terkemuka yang menangani produk digital untuk startup hingga enterprise, membuka lowongan UI/UX Designer untuk tim product design. Sebagai UI/UX Designer, Anda akan bertanggung jawab merancang user experience dan interface yang intuitif, engaging, dan accessible untuk aplikasi mobile dan web. Anda akan bekerja closely dengan product manager, developer, dan stakeholder untuk memastikan design yang implementable dan memenuhi user needs. Posisi ini cocok untuk designer yang passionate tentang user-centered design dan ingin berkembang dalam product design.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2-3 tahun pengalaman sebagai UI/UX Designer atau Product Designer
  • Proficiency dalam design tools: Figma (required), Adobe XD atau Sketch
  • Strong understanding user research, persona development, dan user journey mapping
  • Excellent visual design skills dengan sense of typography, color, dan spacing
  • Knowledge web accessibility standards: WCAG, semantic HTML basics
  • Experience dengan design systems dan component-based design
  • Portfolio dengan 3-5 project case studies menunjukkan design process
  • Familiarity dengan Agile/Scrum development workflow

Tanggung Jawab

  • Conduct user research dan create personas, user journeys, wireframes
  • Design UI mockups dan prototypes dalam Figma dengan high fidelity
  • Create interactive prototypes untuk user testing dan validation
  • Develop dan maintain design system dan component library
  • Collaborate dengan frontend developer untuk implementation handoff
  • Conduct usability testing dan iterate design based pada user feedback
  • Create and document design specifications dan style guides
  • Stay updated dengan latest design trends dan best practices

Benefit

  • Gaji kompetitif Rp 8-13 Juta + bonus + THR
  • BPJS Kesehatan dan Ketenagakerjaan
  • Asuransi kesehatan
  • Laptop MacBook atau high-spec untuk design work
  • Budget professional development: design courses, conferences
  • Flexible working arrangement dengan WFH option
  • Creative working environment dengan supportive team
  • Career path ke Lead Designer atau Design Director
