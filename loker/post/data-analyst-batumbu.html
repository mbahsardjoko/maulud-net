Data Analyst

🏢 Batumbu 📍 Jakarta Raya 💼 Full-time 💰 Rp 10-18 Juta 📅 2026-07-16
Full-time Teknologi

Batumbu, perusahaan teknologi yang fokus pada solusi data dan analytics untuk bisnis, mencari Data Analyst untuk tim mereka di Jakarta. Kamu akan bertanggung jawab mentransformasikan data mentah menjadi insight yang bermakna untuk mendukung keputusan bisnis. Peran ini melibatkan data exploration, dashboarding, reporting, dan kolaborasi dengan stakeholder bisnis untuk memahami kebutuhan analytics mereka.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 2-3 tahun sebagai Data Analyst / Business Intelligence Analyst
  • Mahir SQL (PostgreSQL, MySQL, BigQuery) untuk query kompleks dan optimization
  • Mahir tools visualisasi: Tableau, Power BI, Metabase, atau Superset
  • Mahir Python (pandas, numpy) atau R untuk data analysis dan automation
  • Paham statistik deskriptif, A/B testing, cohort analysis
  • Pengalaman data modeling: dimensional modeling, star/snowflake schema
  • Familiar dengan ETL/ELT pipeline dan data warehouse concepts
  • Kemampuan storytelling dengan data dan presentasi ke stakeholder non-teknis

Tanggung Jawab

  • Menganalisis data bisnis untuk mengidentifikasi trend, pola, dan opportunity
  • Membangun dan memelihara dashboard KPI untuk berbagai tim (Product, Marketing, Ops, Finance)
  • Merancang dan mengimplementasikan data pipeline untuk reporting otomatis
  • Berkolaborasi dengan stakeholder untuk definisi metrics dan data requirements
  • Melakukan ad-hoc analysis untuk support strategic decision making
  • Monitoring data quality dan mengusulkan improvement pada data infrastructure
  • Mendokumentasikan data dictionary, metric definitions, dan analysis methodology

Benefit

  • Gaji kompetitif Rp 10-18 Juta/bulan + performance bonus
  • BPJS Kesehatan, Ketenagakerjaan, Asuransi Jiwa
  • Hybrid work: fleksibel WFO/WFH sesuai kebutuhan proyek
  • Laptop high-spec disediakan (MacBook/Windows high-end)
  • Budget learning: kursus data, sertifikasi, konferensi, buku
  • Akses ke tools analytics premium (Tableau, dbt, Snowflake, dll)
  • Makan siang & snack, coffee bar di kantor
  • Cuti tahunan 12+ hari, parental leave, wellness program
