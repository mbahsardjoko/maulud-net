UI/UX Designer

🏢 Electrum 📍 Jakarta Selatan 💼 Full-time 💰 Rp 12-20 Juta 📅 2026-07-16
Full-time Desain

Electrum, perusahaan teknologi finansial yang menyediakan solusi pembayaran digital dan loyalty platform untuk enterprise, mencari UI/UX Designer untuk tim produk mereka. Kamu akan merancang pengalaman pengguna yang intuitif, efisien, dan visual engaging di seluruh ekosistem digital Electrum — mulai dari mobile apps, web applications, hingga partner dashboards. Peran ini berkolaborasi dekat dengan Product Manager dan Engineering untuk translate requirement ke solusi desain yang scalable.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3-4 tahun sebagai UI/UX Designer / Product Designer
  • Portfolio yang menunjukkan proses desain end-to-end: research, wireframe, prototype, high-fidelity
  • Mahir Figma, prototyping tools, design system creation
  • Paham user research methods: usability testing, user interview, heuristic evaluation
  • Pengalaman desain untuk mobile (iOS/Android) dan responsive web
  • Familiar dengan design handoff ke developer (Zeplin, Figma inspect)
  • Paham accessibility guidelines (WCAG) dan design system maintenance
  • Kemampuan komunikasi desain ke stakeholder non-desain

Tanggung Jawab

  • Merancang user flow, wireframe, prototype, dan high-fidelity mockup untuk fitur-fitur baru
  • Melakukan user research dan usability testing untuk validasi desain
  • Membangun dan memelihara design system yang konsisten di seluruh produk
  • Berkolaborasi dengan Product Manager untuk definisi requirement dan scope
  • Bekerja sama dengan Engineering untuk design handoff dan quality assurance implementasi
  • Mengoptimalkan conversion rate melalui UX improvement berbasis data
  • Membuat design documentation dan style guide untuk tim

Benefit

  • Gaji kompetitif Rp 12-20 Juta/bulan + performance bonus
  • BPJS Kesehatan, Ketenagakerjaan, Asuransi Jiwa
  • Hybrid work: 3 hari WFO (Jakarta Selatan), 2 hari WFH fleksibel
  • MacBook Pro + monitor eksternal + budget setup WFH
  • Learning budget: kursus desain, konferensi, buku, tools subscription
  • Makan siang & snack gratis di kantor
  • Annual leave 14+ hari, cuti sakit, parental leave
  • Kesempatan kerja pada produk fintech B2B enterprise skala besar
