Senior Software Test Engineer (Technical)

🏢 CSG 📍 Jakarta / Hybrid 💼 Full-time 💰 Rp 18-28 Juta 📅 2026-07-16
Full-time Teknologi

CSG, penyedia solusi BSS/OSS dan digital monetization untuk telekomunikasi dan media global, mencari Senior Software Test Engineer untuk tim R&D di Jakarta. Kamu akan bertanggung jawab testing fitur produk CSG Quote & Order menggunakan modern tools: Karate (API), Cypress (UI), dan k6 (Performance). Posisi ini cocok untuk QA engineer yang ingin mendalami technical testing, automation, dan performance engineering di skala enterprise telecom.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 4-6 tahun sebagai Software Test Engineer / QA Engineer / SDET
  • Mahir test automation: Karate (API testing), Cypress (UI/E2E), k6 (Performance)
  • Pengalaman testing sistem BSS/OSS, telecom, billing, atau order management
  • Paham CI/CD pipeline integration: GitLab CI, Jenkins, GitHub Actions untuk test automation
  • Mahir scripting: JavaScript/TypeScript, Python, atau Java untuk test framework
  • Pengalaman performance testing: load, stress, soak, spike testing dengan k6/JMeter
  • Familiar dengan Docker, Kubernetes untuk test environment provisioning
  • Kemampuan debugging, root cause analysis, dan komunikasi temuan ke developer

Tanggung Jawab

  • Mengembangkan dan memelihara test automation suite: API (Karate), UI (Cypress), Performance (k6)
  • Merancang test strategy dan test plan untuk fitur-fitur baru produk Quote & Order
  • Melakukan functional, integration, regression, dan performance testing
  • Mengintegrasikan automated test ke CI/CD pipeline untuk continuous testing
  • Berkolaborasi dengan developer untuk shift-left testing: unit test, contract test, code review
  • Menganalisis performance bottleneck: latency, throughput, resource utilization
  • Membuat test report, metrics dashboard, dan rekomendasi improvement
  • Menjadi Subject Matter Expert untuk testing tools dan best practices di tim

Benefit

  • Gaji kompetitif Rp 18-28 Juta/bulan + performance bonus + RSU
  • BPJS Kesehatan, Ketenagakerjaan, Asuransi Jiwa lengkap
  • Hybrid work: 3 hari WFO Jakarta, 2 hari WFH
  • MacBook Pro / high-spec laptop + monitor + peripherals
  • Learning budget: certification (ISTQB, AWS, Kubernetes), conference, course
  • Exposure teknologi telecom global, skala enterprise, modern stack
  • Cuti tahunan 14+ hari, parental leave, wellness program
