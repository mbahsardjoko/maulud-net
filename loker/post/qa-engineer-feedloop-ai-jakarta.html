Quality Assurance Engineer

🏢 Feedloop AI 📍 Jakarta Raya, Indonesia 💼 Full-time 💰 Rp 8-14 Juta 📅 2026-08-06
Full-time Teknologi

Feedloop AI, startup AI conversational platform yang berkembang pesat di Indonesia, membuka lowongan Quality Assurance Engineer. Kamu akan bertanggung jawab memastikan kualitas produk melalui automated end-to-end (E2E) testing. Posisi ini cocok untuk QA Engineer yang memiliki pengalaman kuat dalam test automation dan ingin bekerja di lingkungan AI/ML yang inovatif.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 2 tahun sebagai QA Engineer / Software Tester
  • Mahir menulis automated test E2E menggunakan framework modern (Playwright, Cypress, atau Selenium)
  • Paham konsep test pyramid, test strategy, dan CI/CD integration
  • Pengalaman testing aplikasi web berbasis React/Vue dan REST API
  • Familiar dengan TypeScript/JavaScript untuk test scripting
  • Kemampuan analisis root cause bug dan komunikasi dengan developer
  • Berkedudukan di Jakarta Raya (hybrid/onsite)

Tanggung Jawab

  • Merancang dan mengimplementasikan test automation suite (E2E, integration)
  • Menyusun test plan, test case, dan test data untuk fitur baru
  • Mengintegrasikan automated test ke pipeline CI/CD (GitHub Actions/GitLab CI)
  • Melakukan manual testing exploratory untuk validasi UX dan edge case
  • Berkolaborasi dengan developer untuk reproduksi dan verifikasi bug fix
  • Memonitor flaky test dan maintain test suite reliability
  • Menyusun laporan kualitas rilis (release quality report)

Benefit

  • Gaji Rp 8-14 Juta + bonus performa
  • BPJS Kesehatan dan Ketenagakerjaan
  • Bekerja di startup AI conversational platform terdepan
  • Flexible working arrangement (hybrid)
  • Budget learning dan sertifikasi QA/testing
  • Stock option (ESOP) untuk karyawan awal
  • Lingkungan kerja inovatif dengan tech stack modern
