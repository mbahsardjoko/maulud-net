Network Engineer

🏢 PT Sapta Tunas Teknologi 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 7-12 Juta 📅 2026-08-31
Full-time Teknologi

PT Sapta Tunas Teknologi, perusahaan solusi IT terpercaya yang bergerak di bidang network infrastructure, managed services, dan IT consulting untuk klien korporat dan instansi pemerintahan di Indonesia, sedang membuka lowongan Network Engineer untuk memperkuat tim technical operation mereka. Posisi ini sangat cocok untuk engineer yang ingin mengelola dan membangun infrastruktur jaringan berskala enterprise, mulai dari desain topologi, implementasi perangkat jaringan, hingga monitoring dan troubleshooting 24/7. Anda akan bekerja dengan berbagai vendor teknologi terkemuka seperti Cisco, MikroTik, Juniper, dan Fortinet dalam proyek-proyek infrastruktur jaringan untuk klien strategis.

📎 Sumber: Kalibrr

Kualifikasi

  • Minimal 2 tahun pengalaman sebagai Network Engineer atau NOC Engineer
  • Paham konsep networking: TCP/IP, routing, switching, firewall, dan VPN
  • Pengalaman konfigurasi perangkat jaringan: Cisco IOS, MikroTik RouterOS, atau Juniper JunOS
  • Sertifikasi networking menjadi nilai plus: CCNA, CCNP, MikroTik MTCNA, atau CompTIA Network+
  • Familiar dengan monitoring tools: Zabbix, PRTG, Nagios, atau Grafana
  • Pengalaman wireless networking: MikroTik, Ubiquiti, atau Cisco WLC
  • Kemampuan troubleshooting jaringan kompleks dan analisis packet menggunakan Wireshark
  • Bertanggung jawab dan siap on-call untuk support jaringan di luar jam kerja
  • S1 Teknik Informatika, Teknik Elektro, atau sertifikasi di bidang networking

Tanggung Jawab

  • Menginstalasi, mengkonfigurasi, dan mengelola perangkat jaringan: router, switch, firewall, access point
  • Merancang dan mengimplementasikan topologi jaringan enterprise untuk klien korporat
  • Melakukan monitoring jaringan 24/7 dan merespons insiden jaringan sesuai SLA
  • Troubleshoot connectivity issues, performance degradation, dan security incidents
  • Menyusun dokumentasi jaringan: network diagram, IP addressing plan, dan configuration backup
  • Melakukan maintenance rutin: firmware update, security patch, dan performance tuning
  • Koordinasi dengan vendor dan ISP untuk resolve escalation jaringan
  • Mendukung project deployment infrastruktur baru: site survey, rancang, implementasi, commissioning

Benefit

  • Gaji kompetitif Rp 7-12 Juta + allowance transport + THR
  • BPJS Kesehatan dan Ketenagakerjaan
  • Asuransi kesehatan untuk karyawan
  • Budget sertifikasi: CCNA, CCNP, MikroTik, atau sertifikasi lainnya
  • Peralatan kerja disediakan termasuk laptop dan measurement tools
  • Lingkungan kerja IT infrastructure yang stabil dan berkembang
  • Exposure ke berbagai site klien korporat dan instansi pemerintah
  • Training dan career development path yang jelas
