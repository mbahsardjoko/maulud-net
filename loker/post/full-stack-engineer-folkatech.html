Folkatech, software development company yang dipercaya berbagai bisnis di Indonesia untuk membangun custom software solution, membuka lowongan Full Stack Engineer. Kamu akan bekerja pada berbagai project menarik — dari enterprise web application, SaaS platform, hingga mobile app backend — menggunakan stack modern. Cocok untuk engineer yang suka variety project, cepat belajar tech baru, dan ingin tumbuh di lingkungan konsultansi teknologi.

  • S1 Teknik Informatika / Ilmu Komputer / bidang terkait (atau self-taught dengan portofolio kuat)

  • Backend: Mahir Node.js (NestJS/Express) atau Go, RESTful API, GraphQL

  • DevOps basic: Docker, CI/CD (GitHub Actions/GitLab CI), cloud (AWS/GCP/Azure)
  • Pemahaman testing: unit, integration, e2e (Jest, Playwright, Cypress)
  • Git workflow (GitFlow/Trunk-based), code review culture
  • Komunikasi baik, bisa presentasi teknis ke klien non-teknis
