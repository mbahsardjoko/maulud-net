Data Engineer

🏢 PT Lautan Luas Tbk 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 9-15 Juta 📅 2026-09-01
Full-time Teknologi

PT Lautan Luas Tbk, distributor bahan kimia dan pharmaceutical terbesar di Indonesia, membuka lowongan Data Engineer untuk memperkuat tim data analytics mereka. Sebagai Data Engineer, Anda akan bertanggung jawab mengembangkan data infrastructure yang mendukung business intelligence dan decision-making process di level manajemen. Perusahaan ini memiliki complex supply chain dan inventory management yang membutuhkan sophisticated data pipeline untuk real-time analytics. Posisi ini menawarkan kesempatan untuk bekerja dengan enterprise-scale data dan business-critical systems.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2 tahun pengalaman sebagai Data Engineer atau Business Intelligence Engineer
  • Proficient dalam SQL: advanced queries, window functions, query optimization
  • Pengalaman dengan ETL tools: Apache Airflow, Informatica, Talend, atau similar
  • Familiar dengan data warehouse concept dan dimensional modeling
  • Pengalaman dengan Python atau similar language untuk data processing
  • Knowledge database systems: PostgreSQL, MySQL, SQL Server, atau Oracle
  • Familiar dengan BI tools: Tableau, Power BI, atau Looker
  • Basic understanding cloud platforms: AWS atau Azure (nice to have)

Tanggung Jawab

  • Design dan develop data pipeline untuk extract, transform, dan load data dari multiple sources
  • Maintain dan optimize existing ETL processes
  • Collaborate dengan Data Analysts dan Business users untuk gather requirements
  • Ensure data quality, consistency, dan accuracy dalam data warehouse
  • Monitor ETL pipeline performance dan troubleshoot data issues
  • Create dan maintain documentation untuk data dictionary dan data lineage
  • Implement security dan compliance measures untuk sensitive data
  • Support ad-hoc data requests dari business stakeholders

  • Asuransi kesehatan untuk karyawan dan keluarga
  • Laptop disediakan
