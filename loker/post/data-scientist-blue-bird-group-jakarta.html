Data Scientist

🏢 Blue Bird Group 📍 Jakarta Raya, Indonesia 💼 Full-time 💰 Rp 18-30 Juta 📅 2026-07-28
Full-time Teknologi

Blue Bird Group, perusahaan transportasi terbesar dan terpercaya di Indonesia yang mengoperasikan armada taksi, bus, dan layanan logistik, membuka lowongan Data Scientist untuk bergabung dengan tim Data & Analytics. Kamu akan bertanggung jawab mengembangkan model machine learning dan predictive analytics untuk mengoptimalkan operasional armada, pricing dinamis, demand forecasting, dan personalisasi layanan pelanggan. Posisi ini menawarkan tantangan unik menerapkan AI/ML pada skala besar di industri transportasi dan logistik nasional.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal S2 di bidang Data Science, Computer Science, Statistics, Mathematics, atau terkait (S1 dengan pengalaman exceptional diterima)
  • Pengalaman 3+ tahun sebagai Data Scientist atau Machine Learning Engineer
  • Mahir dalam Python (pandas, scikit-learn, TensorFlow/PyTorch, XGBoost/LightGBM)
  • Pengalaman kuat dengan statistical modeling, time series forecasting, dan NLP
  • Familiar dengan big data processing (Spark, Hadoop, atau cloud data platforms)
  • Pengalaman deploy ML models ke production (MLOps, Docker, Kubernetes, CI/CD)
  • Pemahaman tentang causal inference, A/B testing, dan experimental design
  • Kemampuan storytelling dengan data dan presentasi ke stakeholder non-teknis
  • Bersedia bekerja on-site/hybrid di Jakarta Raya

Tanggung Jawab

  • Mengembangkan dan deploy ML models untuk demand forecasting dan dynamic pricing
  • Membangun recommendation system dan personalisasi untuk aplikasi pelanggan
  • Melakukan analisis pola pergerakan armada dan optimasi rute
  • Merancang dan mengeksekusi A/B testing framework untuk eksperimen produk
  • Berkolaborasi dengan data engineer untuk pipeline data yang scalable
  • Menyajikan insight dan rekomendasi strategis ke leadership team
  • Mengembangkan MLOps best practices dan model monitoring
  • Mentoring junior data scientist dan analyst di tim
