⭐ AI/ML Engineer

🏢 Genorah Labs Indonesia 🌐 Jakarta / Remote 💼 Full-time 💰 Rp 18-30 Juta 📅 2026-09-04
Full-time Teknologi

Genorah Labs Indonesia, perusahaan AI Lab yang fokus pada pengembangan sistem kecerdasan buatan untuk menyelesaikan masalah bisnis nyata, membuka lowongan AI/ML Engineer. Sebagai AI/ML Engineer, Anda akan merancang, membangun, dan men-deploy sistem machine learning ke production — bukan sekadar prototype, melainkan sistem yang benar-benar digunakan oleh pengguna. Fokus utama meliputi pembangunan RAG pipelines, fine-tuning model bahasa besar (LLM), dan pembuatan intelligent agents yang bekerja di dunia nyata. Anda akan berkolaborasi dengan tim product dan engineering untuk mengidentifikasi opportunity AI yang memberikan impact bisnis konkret.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2 tahun pengalaman sebagai AI/ML Engineer atau Machine Learning Engineer
  • Mahir dalam Python untuk ML/DL: PyTorch, TensorFlow, atau JAX
  • Pengalaman membangun dan men-deploy RAG pipelines dan LLM fine-tuning
  • Familiar dengan MLOps: MLflow, Kubeflow, atau Vertex AI
  • Strong fundamentals dalam statistics, linear algebra, dan optimasi
  • Pengalaman dengan cloud platform: AWS, GCP, atau Azure untuk ML workloads
  • Pemahaman deep learning architectures: Transformers, CNN, RNN
  • Mampu mengoptimalkan model untuk inference latency dan cost efficiency
  • Self-driven, mampu bekerja mandiri maupun dalam tim agile

Tanggung Jawab

  • Merancang dan membangun end-to-end ML pipelines dari data ingestion hingga serving
  • Mengembangkan dan men-deploy RAG (Retrieval-Augmented Generation) systems
  • Fine-tune large language models untuk use case spesifik perusahaan
  • Membuat intelligent agents yang mengotomatisasi proses bisnis
  • Collaborate dengan product team untuk translate business problems ke ML solutions
  • Monitor model performance, debugging, dan continuous improvement
  • Write clean, maintainable ML code dengan proper testing dan documentation
  • Evaluate dan select appropriate ML models dan techniques berdasarkan requirements

Benefit

  • Gaji kompetitif Rp 18-30 Juta + performance bonus + equity (for senior roles)
  • BPJS Kesehatan dan Ketenagakerjaan
  • Asuransi kesehatan premium untuk karyawan dan keluarga
  • Laptop MacBook Pro + GPU credits untuk eksperimen ML
  • Budget conference, certifications AI/ML (Rp 30jt/tahun)
  • Flexible working: full remote atau hybrid dengan jam fleksibel
  • Kesempatan mengerjakan cutting-edge AI projects dengan impact nyata
  • Tim engineering yang solid dengan focus kuat di AI/ML
  • Akses ke latest AI research papers dan tools
