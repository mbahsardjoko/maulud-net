QA Engineer Intern

🏢 IDN 📍 Surabaya, Jawa Timur, Indonesia 💼 Internship 💰 Rp 3-5 Juta 📅 2026-08-18
Internship Teknologi

IDN, platform media dan komunitas generasi muda terbesar di Indonesia, membuka lowongan QA Engineer Intern berbasis Surabaya. Program magang ini memberikan kesempatan hands-on untuk belajar quality assurance software di lingkungan production nyata. Kamu akan bekerja sama dengan tim QA senior untuk memastikan kualitas aplikasi mobile dan web yang digunakan jutaan pengguna. Cocok untuk fresh graduate atau mahasiswa semester akhir yang ingin memulai karir di software testing.

📎 Sumber: LinkedIn

Kualifikasi

  • Mahasiswa semester akhir atau fresh graduate S1 Ilmu Komputer / Sistem Informasi
  • Paham konsep dasar Software Testing (STLC, bug life cycle, test case design)
  • Familiar dengan alat testing: Postman, JIRA, TestRail, atau sejenisnya
  • Pemahaman dasar HTML, CSS, JavaScript, dan HTTP/REST API
  • Detail-oriented, analitis, dan memiliki ketelitian tinggi
  • Kemampuan komunikasi dan dokumentasi yang baik
  • Bersedia magang full-time minimal 6 bulan di Surabaya
  • Passion untuk belajar QA automation (Selenium, Cypress, Playwright) menjadi nilai plus

Tanggung Jawab

  • Membuat dan mengeksekusi test case untuk fitur baru dan regression
  • Melakukan functional testing, UI testing, dan API testing
  • Mencatat, melacak, dan memverifikasi bug fix di JIRA
  • Berkolaborasi dengan developer dan product manager untuk klarifikasi requirement
  • Membantu tim QA senior dalam test planning dan test strategy
  • Belajar dan mencoba QA automation tools (Selenium, Cypress, Playwright)
  • Membuat laporan testing harian/mingguan
  • Berpartisipasi dalam release testing dan UAT support
