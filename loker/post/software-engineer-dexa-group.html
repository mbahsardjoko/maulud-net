⭐ Software Engineer (Junior/Middle/Senior)

🏢 Dexa Group 📍 Tangerang Selatan 💼 Full-time 💰 Kompetitif (Negotiable) 📅 2026-06-24
Full-time Teknologi

Dexa Group, salah satu perusahaan farmasi etikal terbesar di Indonesia, sedang membuka kesempatan bagi Software Engineer di semua level (Junior, Middle, Senior). Posisi ini berlokasi di Bintaro, Tangerang Selatan, dan terbuka untuk fresh graduate maupun yang sudah berpengalaman. Kamu akan bertanggung jawab merancang dan mengembangkan fitur baru untuk aplikasi web dan mobile, serta memastikan performa dan kestabilan aplikasi tetap optimal.

📎 Sumber: Dealls

Kualifikasi

  • Sarjana Teknologi Informasi dari universitas terkemuka
  • Fresh graduate dipersilakan melamar, atau pengalaman 1-5+ tahun
  • Pemahaman mendalam tentang backend: Node.js, NestJS
  • Pemahaman mendalam tentang frontend: Tailwind, JavaScript, TypeScript, React
  • Pengalaman dengan database: MySQL, Redis, MongoDB, atau PostgreSQL
  • Kepemimpinan dan kemampuan mentoring yang kuat
  • Pengetahuan tentang ERP (Manufacturing, SCM, PLM) menjadi nilai tambah
  • Bersedia bekerja on-site dan full-time di Bintaro, Tangerang Selatan

Tanggung Jawab

  • Merancang dan mengembangkan fitur baru untuk aplikasi web dan mobile
  • Memelihara dan memperbarui kode sumber aplikasi untuk menjaga stabilitas dan performa
  • Membuat antarmuka pengguna yang responsif dan menarik menggunakan Tailwind, JavaScript, dan/atau TypeScript
  • Mengembangkan layanan backend menggunakan Node.js, NestJS, dan/atau Express.js
  • Mengelola dan mengoptimalkan database aplikasi
  • Melakukan pengujian dan debugging untuk memastikan kualitas dan keamanan aplikasi
  • Berkolaborasi dengan tim produk dan desain untuk memahami kebutuhan pengguna

Benefit

  • Gaji kompetitif
  • THR / Bonus
  • Asuransi kesehatan
  • Makan siang gratis
  • Paparan internasional
