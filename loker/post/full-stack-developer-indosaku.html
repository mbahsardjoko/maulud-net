Full Stack Developer

🏢 Indosaku 📍 Tangerang Selatan 💼 Full-time 💰 Rp 7-12 Juta 📅 07 Juni 2026
Full-time Teknologi

Indosaku, perusahaan financial technology (fintech) yang berkembang pesat, mencari Full Stack Developer untuk merancang dan mengembangkan arsitektur aplikasi end-to-end. Posisi ini membutuhkan penguasaan Java dengan Spring Boot di sisi backend dan salah satu framework frontend modern. Kamu akan bertanggung jawab dalam mengembangkan fitur baru, integrasi API, dan memastikan keamanan aplikasi dari sisi backend maupun frontend.

📎 Sumber: LinkedIn

Kualifikasi

  • Pendidikan minimal D3/S1 di bidang IT atau terkait
  • Pengalaman kerja 2-3 tahun sebagai Software Developer
  • Menguasai Java dan konsep OOP
  • Berpengalaman dengan Spring Boot (REST API, Spring Data JPA/Hibernate, Spring Security)
  • Memahami database MySQL dan optimasi query
  • Menguasai HTML, CSS, JavaScript serta framework frontend (React, Angular, atau Vue)
  • Terbiasa menggunakan Git untuk version control
  • Memahami RESTful API, JSON, XML, dan dasar keamanan aplikasi

Tanggung Jawab

  • Merancang arsitektur aplikasi end-to-end
  • Mengembangkan fitur baru sesuai kebutuhan bisnis
  • Memastikan keamanan aplikasi dari sisi backend dan frontend
  • Melakukan troubleshooting dan bug fixing
  • Mengintegrasikan API dan layanan eksternal
  • Menyusun serta memelihara dokumentasi teknis aplikasi

Benefit

  • Gaji kompetitif sesuai pengalaman
  • Lingkungan kerja startup yang dinamis
  • BPJS Kesehatan & Ketenagakerjaan
  • Kesempatan pengembangan karir
  • Tunjangan transportasi
