Software Engineer (Fresh Graduates)

🏢 LG Sinar Mas (LG CNS Indonesia) 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 7-11 Juta 📅 2026-08-02
Full-time Teknologi

LG Sinar Mas, joint venture antara LG CNS (perusahaan IT #1 Korea) dan Sinarmas Group, membuka program Fresh Graduate Software Engineer. Program ini dirancang untuk lulusan terbaik yang ingin memulai karir di perusahaan IT services terdepan di Indonesia. Anda akan mendapatkan training intensif 6 bulan mencakup .NET, Java, cloud, dan modern development practices, serta dibimbing oleh senior engineer berpengalaman dari Korea dan Indonesia.

📎 Sumber: LinkedIn

Kualifikasi

  • Fresh graduate S1 Teknik Informatika, Sistem Informasi, atau jurusan terkait (angkatan 2025/2026)
  • IPK minimal 3.00 skala 4.00
  • Fundamental programming yang kuat (OOP, data structures, algorithms)
  • Pemahaman dasar .NET (C#) atau Java (Spring Boot)
  • Database basics: SQL, relational database concepts
  • Kemampuan Bahasa Inggris aktif (technical reading/writing)
  • Passion belajar teknologi baru dan problem solving
  • Bersedia menjalani training intensif 6 bulan di Jakarta
  • Growth mindset dan adaptabilitas tinggi

Tanggung Jawab

  • Mengikuti program training intensif 6 bulan (technical + soft skills)
  • Belajar .NET/Java enterprise development best practices
  • Bekerja pada project nyata di bawah bimbingan senior mentor
  • Mengembangkan fitur untuk enterprise applications
  • Menulis clean code, unit tests, dan documentation
  • Belajar cloud platforms (Azure, AWS) dan DevOps basics
  • Berkolaborasi dalam tim Agile/Scrum
  • Presentasi progress project dan demo ke stakeholders

Benefit

  • Gaji kompetitif fresh grad (Rp 7-11 Juta) + allowances
  • BPJS Kesehatan dan Ketenagakerjaan dari hari pertama
  • Program training terstruktur 6 bulan oleh LG CNS experts
  • Mentoring 1-on-1 dari senior engineers
  • Asuransi kesehatan comprehensive
  • Kesempatan assignment/project ke Korea (LG CNS HQ)
  • Clear career path: Junior → Mid → Senior → Tech Lead
  • Modern office di CBD Jakarta dengan fasilitas lengkap
