⭐ Software Engineer

🏢 GoTo Group (Gojek + Tokopedia) 📍 Jakarta / Hybrid 💼 Full-time 💰 Rp 15-30 Juta 📅 2026-07-15
Full-time Teknologi

GoTo Group, ekosistem digital terbesar di Indonesia yang menggabungkan Gojek, Tokopedia, dan GoTo Financial, mencari Software Engineer untuk bergabung membangun platform teknologi yang melayani jutaan pengguna sehari-hari. Kamu akan bekerja pada sistem skala besar: ride-hailing, e-commerce, pembayaran digital, dan layanan keuangan. Tim engineering GoTo menggunakan tech stack modern (Go, Java, Kotlin, React, Kafka, Kubernetes) dengan budaya engineering excellence dan open source contribution.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 2-3 tahun sebagai Software Engineer / Backend Engineer
  • Mahir dalam Go (Golang) dan/atau Java/Kotlin (Spring Boot)
  • Pengalaman dengan microservices architecture, gRPC, RESTful API
  • Paham message queue (Kafka, RabbitMQ) dan event-driven architecture
  • Pengalaman dengan database PostgreSQL, MySQL, Redis, Cassandra
  • Familiar dengan containerization (Docker) dan orchestration (Kubernetes)
  • Paham CI/CD pipeline, observability (Prometheus, Grafana, Jaeger)
  • Kemampuan problem-solving kuat dan bisa kerja kolaboratif lintas tim

Tanggung Jawab

  • Mendesain dan mengembangkan layanan backend scalable untuk produk GoTo
  • Mengoptimalkan performa sistem high-throughput low-latency
  • Berpartisipasi dalam system design review dan architecture decision
  • Membangun internal developer tools dan platform infrastructure
  • Melakukan code review, mentoring junior engineer, sharing knowledge
  • Berkolaborasi dengan Product Manager, Data Scientist, SRE untuk deliver fitur
  • Menjaga kualitas kode: testing, documentation, security best practices

Benefit

  • Gaji kompetitif Rp 15-30 Juta/bulan + bonus performa + stock option (ESOP)
  • BPJS Ketenagakerjaan, Kesehatan, Asuransi Jiwa komprehensif
  • Hybrid work arrangement (3 hari WFO, 2 hari WFH)
  • MacBook Pro M-series / high-spec laptop + monitor eksternal
  • Budget belajar tidak terbatas: sertifikasi, konferensi, kursus, buku
  • Akses ke ekosistem GoTo: diskon Gojek, Tokopedia, GoTo Financial
  • Makan siang gratis, snack bar, gym access di kantor Jakarta
  • Program wellness: mental health support, medical check-up tahunan
