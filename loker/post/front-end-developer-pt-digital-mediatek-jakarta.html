Front End Developer

🏢 PT Digital Mediatek Solusindo (DMS Group) 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 7-14 Juta 📅 2026-07-24
Full-time Teknologi

PT Digital Mediatek Solusindo (DMS Group), perusahaan teknologi yang bergerak di bidang solusi digital, pengembangan software, dan layanan IT terintegrasi, membuka lowongan Front End Developer di Jakarta. Kamu akan menjadi bagian dari tim pengembangan yang menangani berbagai proyek klien mulai dari enterprise application, e-commerce platform, hingga mobile web application. Posisi ini menawarkan kesempatan untuk bekerja pada proyek-proyek yang beragam dengan stack teknologi modern, cocok untuk developer yang suka tantangan dan ingin terus belajar.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 1-3 tahun pengalaman sebagai Front End Developer
  • Mahir dalam Vue.js (Vue 2/3) atau React.js
  • Pemahaman kuat tentang HTML5, CSS3, JavaScript (ES6+)
  • Pengalaman dengan CSS framework (TailwindCSS, Bootstrap, atau Vuetify)
  • Familiar dengan state management (Vuex/Pinia atau Redux/Zustand)
  • Pengalaman konsumsi RESTful API dan GraphQL
  • Paham Git version control dan branching strategy
  • Kemampuan problem-solving dan komunikasi tim yang baik
  • Bersedia bekerja full-time di Jakarta (WFO/hybrid)

Tanggung Jawab

  • Mengembangkan antarmuka pengguna untuk berbagai proyek klien menggunakan Vue.js/React.js
  • Menerjemahkan desain UI/UX dari Figma ke implementasi kode yang responsif
  • Berkolaborasi dengan backend developer untuk integrasi API
  • Melakukan optimasi performa frontend dan memastikan cross-browser compatibility
  • Menulis kode yang bersih, modular, dan mudah dipelihara
  • Berpartisipasi dalam code review, daily standup, dan sprint planning
  • Membangun dan memelihara design system/component library internal
  • Mendukung troubleshooting dan bug fixing di production

Benefit

  • Gaji kompetitif + bonus kinerja proyek
  • BPJS Kesehatan dan Ketenagakerjaan
  • Asuransi kesehatan tambahan
  • Laptop kerja disediakan
  • Budget pelatihan dan buku teknis
  • Snack dan minuman gratis di kantor
  • Tim yang suportif dan culture belajar
  • Kesempatan kerja pada proyek beragam industri
