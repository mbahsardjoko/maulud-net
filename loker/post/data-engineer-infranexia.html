Data Engineer

🏢 Infranexia (Telkom Infrastruktur Indonesia) 🌐 Jakarta (On-site, occasional remote) 💼 Full-time 💰 Kompetitif (sesuai standar industri) 📅 23 June 2026
Full-time Teknologi

Infranexia, bagian dari Telkom Infrastruktur Indonesia, sedang membangun centralized data platform untuk mengotomatisasi KPI enterprise dan inisiatif AI. Posisi Data Engineer akan bertanggung jawab merancang serta memelihara pipeline data dan data warehouse yang mengubah data operasional dari berbagai source system menjadi informasi yang andal dan siap pakai untuk kebutuhan analytics. Peran ini cocok untuk engineer yang ingin berkontribusi pada transformasi data di salah satu perusahaan infrastruktur telekomunikasi terbesar di Indonesia.

📎 Sumber: LinkedIn Indonesia

Kualifikasi

  • Pengalaman 2-4 tahun sebagai Data Engineer atau posisi terkait
  • Mahir SQL dan salah satu bahasa pemrograman data (Python/Scala)
  • Pengalaman dengan tools ETL/ELT modern (Airflow, dbt, Spark, atau Kafka)
  • Paham arsitektur data warehouse, data lake, dan data modeling (star/snowflake schema)
  • Familiar dengan cloud platform (GCP, AWS, atau Azure) dan layanan data-nya
  • Pengalaman dengan BigQuery, Snowflake, atau Redshift menjadi nilai tambah
  • Mampu berkomunikasi dengan stakeholder bisnis dan menerjemahkan kebutuhan menjadi solusi data

Tanggung Jawab

  • Merancang, membangun, dan memelihara pipeline data (ETL/ELT) dari multiple sources
  • Mengembangkan data warehouse yang reliable, scalable, dan terdokumentasi
  • Berkolaborasi dengan tim analytics, data science, dan product dalam menyediakan dataset siap pakai
  • Menjaga kualitas data, monitoring pipeline, dan menangani incident data
  • Mengoptimasi performa query dan efisiensi penyimpanan data
  • Mendukung inisiatif AI enterprise dengan menyediakan infrastruktur data yang siap

Benefit

  • Bekerja pada proyek data strategis di infrastruktur telekomunikasi nasional
  • Akses ke stack data modern dan cloud platform
  • Tim engineering yang fokus pada kualitas dan best practice
  • Lingkungan kerja hybrid dengan fleksibilitas remote occasional
  • Kompensasi dan benefit sesuai standar industri
