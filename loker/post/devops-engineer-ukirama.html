DevOps Engineer

🏢 Ukirama 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 10-18 Juta 📅 2026-07-31
Full-time Teknologi

Ukirama membuka lowongan DevOps Engineer untuk tim di Jakarta. Kandidat ideal memiliki pengalaman 3-5 tahun mengelola cloud infrastructure dan production environment, dengan pemahaman mendalam tentang Docker, CI/CD pipelines, dan monitoring tools. Kamu akan bertanggung jawab atas ketersediaan, performa, dan keamanan infrastruktur yang mendukung produk digital Ukirama.

📎 Sumber: LinkedIn

Kualifikasi

  • S1 Teknik Informatika / Ilmu Komputer / bidang terkait
  • 3-5 tahun pengalaman sebagai DevOps Engineer, Infrastructure Engineer, atau SRE
  • Pengalaman kuat mengelola cloud infrastructure (AWS/GCP/Azure) di production
  • Mahir Docker/containerization dan CI/CD pipeline automation
  • Pengalaman dengan monitoring tools (Prometheus, Grafana, New Relic, atau sejenisnya)
  • Familiar dengan Infrastructure as Code (Terraform, Ansible, atau sejenisnya)
  • Memahami Linux system administration dan networking fundamentals
  • Kemampuan troubleshooting dan problem solving yang baik
  • Mampu bekerja dalam tim dan komunikasi teknis yang jelas

Tanggung Jawab

  • Mengelola dan memelihara cloud infrastructure di production environment
  • Membangun dan mengoptimalkan CI/CD pipelines untuk deployment otomatis
  • Mengimplementasikan monitoring, logging, dan alerting system
  • Melakukan infrastructure provisioning menggunakan IaC tools
  • Berkolaborasi dengan tim development untuk infrastruktur yang dibutuhkan
  • Melakukan capacity planning dan cost optimization
  • Mengelola incident response dan postmortem untuk production issues
  • Mendokumentasikan arsitektur infrastruktur dan runbook operational

Benefit

  • Asuransi kesehatan tambahan
  • Laptop dan peralatan kerja
  • Budget pembelajaran dan sertifikasi
  • Hybrid work arrangement
  • Tunjangan transport dan makan
  • Lingkungan kerja yang mendukung inovasi teknologi
