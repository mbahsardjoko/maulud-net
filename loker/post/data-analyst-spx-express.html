Full-time Teknologi

SPX Express membuka lowongan Data Analyst untuk bergabung dengan tim data kami. Anda akan menganalisis data bisnis, membuat reports, dan memberikan insights untuk mendukung decision making perusahaan. Posisi ini cocok untuk analyst yang detail-oriented, analytical minded, dan punya passion dalam data visualization.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 1-2 tahun pengalaman sebagai Data Analyst
  • Proficient dalam Google Spreadsheet dan Excel
  • Pengetahuan dasar SQL dan Python
  • Kemampuan data visualization dan storytelling
  • Familiar dengan analytics tools (Google Analytics, Tableau, atau Power BI)
  • Analytical dan problem-solving skills yang kuat
  • Attention to detail dan akurasi data

Tanggung Jawab

  • Menganalisis data bisnis dari berbagai sumber
  • Membuat reports dan dashboards untuk tracking KPI
  • Mengidentifikasi trends dan insights dari data
  • Membuat rekomendasi berdasarkan data analysis
  • Troubleshooting data issues dan data quality
  • Dokumentasi methodology dan analysis process
  • Kolaborasi dengan berbagai departemen untuk data needs

Benefit

  • Training untuk tools dan skills development
  • Hybrid work arrangement
  • Bonus performa
