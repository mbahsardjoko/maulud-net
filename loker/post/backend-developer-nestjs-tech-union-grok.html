🏢 Tech Union Grok (TUG) 🌐 Remote / Indonesia 💼 Full-time 💰 Rp 10-18 Juta 📅 2026-06-30
Full-time Teknologi

Tech Union Grok (TUG) adalah perusahaan teknologi yang fokus pada pengembangan solusi digital inovatif. Saat ini mereka sedang mencari Backend Developer berpengalaman dengan spesialisasi NestJS untuk bergabung dengan tim engineering. Posisi ini akan menjadi pemain kunci dalam merancang, mengembangkan, dan memelihara backend architecture aplikasi menggunakan Node.js dan NestJS. Kamu akan bekerja dalam tim yang menggunakan teknologi modern seperti TypeScript, Docker, dan CI/CD pipelines. Cocok untuk backend developer yang memiliki pengalaman solid dengan NestJS dan ingin bekerja secara remote dengan tim yang dinamis.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2 tahun pengalaman dengan Node.js, minimal 1 tahun dengan NestJS
  • Pemahaman kuat tentang TypeScript dan JavaScript ES6+
  • Pengalaman dengan relational database (MySQL/PostgreSQL) dan ORM (TypeORM)
  • Familiar dengan Docker dan containerization
  • Pengalaman dengan CI/CD pipelines (GitHub Actions)
  • Pemahaman tentang RESTful API design dan microservices architecture
  • Pengalaman dengan cloud services (AWS/GCP/Firebase) menjadi nilai tambah
  • Kemampuan problem-solving dan komunikasi yang baik

Tanggung Jawab

  • Mengembangkan dan memelihara backend services menggunakan NestJS
  • Merancang dan membangun RESTful API yang scalable dan terstruktur
  • Menulis kode yang bersih, terstruktur, dan terdokumentasi dengan baik
  • Berkolaborasi dengan tim frontend dan DevOps dalam integrasi dan deployment
  • Melakukan code review dan memastikan standar kualitas kode
  • Mengoptimalkan performa database dan backend services
  • Berpartisipasi dalam perencanaan arsitektur teknis

Benefit

  • Bekerja secara remote dari mana saja di Indonesia
  • Tim engineering yang solid dengan standar teknis tinggi
  • Teknologi modern: NestJS, TypeScript, Docker, CI/CD
  • Lingkungan kerja yang fleksibel dan mendukung growth
  • Kompensasi dan benefit kompetitif
