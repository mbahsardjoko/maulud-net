Backend Engineer Project Intern (TikTok Shop by Tokopedia) - 2026 Start

🏢 TikTok (Tokopedia) 📍 Jakarta 💼 Internship 💰 Rp 5-8 Juta (Internship) 📅 2026-07-16
Internship Teknologi

TikTok Shop (operasional di Indonesia oleh Tokopedia) membuka program Project Intern untuk Backend Engineer batch 2026 (BS/MS). Program ini dirancang untuk fresh graduate yang ingin memulai karier di backend engineering skala besar e-commerce. Kamu akan bekerja pada sistem yang melayani jutaan transaksi harian: order management, payment, logistics, seller tools. Tech stack: Go, Java, gRPC, Kafka, Kubernetes, MySQL/Redis. Mentoring langsung dari senior engineer Tokopedia/TikTok.

📎 Sumber: LinkedIn

Kualifikasi

  • Fresh graduate S1/S2 Computer Science atau setara (lulus 2025/2026)
  • Fundamental CS kuat: algoritma, struktur data, OS, networking, database
  • Mahir minimal satu bahasa: Go, Java, Python, atau C++
  • Paham konsep: RESTful API, gRPC, microservices, message queue (Kafka/RabbitMQ)
  • Pengalaman project/internship/backend development (coursework, side project, magang)
  • Familiar dengan Git, Linux, Docker, database SQL (MySQL/PostgreSQL)
  • Bisa join full-time on-site di Jakarta Agustus 2026, komitmen 6-12 bulan
  • Komunikasi Bahasa Indonesia & English aktif (lisan & tulisan)

Tanggung Jawab

  • Mengembangkan fitur backend untuk TikTok Shop: order, payment, logistics, seller center
  • Menulis clean code, unit test, integration test dengan code coverage yang baik
  • Berpartisipasi code review, design review, dan tech sharing session
  • Debugging dan troubleshooting production issue dengan guidance senior engineer
  • Belajar dan menerapkan best practices: observability, CI/CD, security, scalability
  • Berkolaborasi dengan Product Manager, Frontend, QA, SRE untuk deliver fitur
  • Mendokumentasikan technical design, API spec, runbook untuk knowledge sharing

Benefit

  • Internship allowance Rp 5-8 Juta/bulan + housing/transport allowance
  • Mentoring 1-on-1 dari Senior/Staff Engineer Tokopedia/TikTok
  • Exposure sistem e-commerce skala jutaan user, modern tech stack (Go, K8s, Kafka)
  • Kesempatan konversi ke Full-time Software Engineer (SDE-1) post-internship
  • Akses ke TikTok/ByteDance global engineering network & internal tech talks
  • MacBook Pro disediakan, meal allowance, coworking space access
  • Program terstruktur: onboarding, project assignment, mid-term review, final presentation
