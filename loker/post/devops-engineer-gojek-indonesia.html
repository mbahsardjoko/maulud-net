DevOps Engineer

🏢 Gojek (GoTo Group) 📍 Jakarta / Hybrid 💼 Full-time 💰 Rp 18-28 Juta 📅 2026-07-15
Full-time Teknologi

Gojek, bagian dari GoTo Group sebagai platform on-demand terbesar di Indonesia, mencari DevOps Engineer untuk tim Platform Engineering. Kamu akan membangun dan mengelola infrastructure-as-code untuk ribuan microservices yang melayani jutaan order harian: ride-hailing, food delivery, payments, logistics. Fokus pada Kubernetes (EKS/GKE), GitOps (ArgoCD), observability stack, developer platform (Backstage), dan cost optimization (FinOps). Tim ini memungkinkan 500+ engineer deploy ke production ratusan kali sehari dengan aman.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3 tahun DevOps / SRE / Platform Engineer
  • Mahir Kubernetes (EKS/GKE/AKS): controller, operator, CRD, Helm, Kustomize
  • Infrastructure as Code: Terraform (wajib), Crossplane atau Pulumi nilai plus
  • GitOps: ArgoCD / Flux untuk progressive delivery, canary, blue-green deploy
  • CI/CD: GitLab CI, GitHub Actions, Tekton, atau Jenkins pipeline
  • Observability: Prometheus, Grafana, Loki, Tempo, OpenTelemetry, alerting

  • Scripting: Go, Python, atau Bash untuk automation tooling internal

Tanggung Jawab

  • Membangun Internal Developer Platform (Backstage) untuk self-service deploy

  • Menyusun strategi FinOps: right-sizing, spot instances, reserved capacity, chargeback
  • Mengintegrasikan security scanning (SAST, DAST, container scan, SBOM) ke pipeline
  • Mengoptimalkan developer experience: local dev environment, preview env, CLI tools
  • Incident response, RCA, chaos engineering, disaster recovery drills
