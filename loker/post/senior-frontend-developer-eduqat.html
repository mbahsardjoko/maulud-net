Full-time Teknologi

Eduqat, platform edukasi digital yang membantu institusi pendidikan dan perusahaan melakukan transformasi pembelajaran, sedang mencari Senior Frontend Developer untuk memperkuat tim produk. Posisi ini bertanggung jawab memimpin pengembangan antarmuka aplikasi web Eduqat, menjaga kualitas kode frontend, dan berkolaborasi dengan tim desain serta backend untuk menghadirkan pengalaman belajar yang mulus bagi pengguna. Cocok untuk engineer yang ingin mengambil peran kepemimpinan teknis di industri edtech.

📎 Sumber: LinkedIn Indonesia

Kualifikasi

  • Minimal 4 tahun pengalaman profesional sebagai Frontend Developer
  • Mahir React.js (atau Vue/Angular) beserta ekosistemnya (Redux, hooks, dsb)
  • Pengalaman dengan TypeScript dan modern JavaScript (ES6+)
  • Paham prinsip responsive design, accessibility, dan performance optimization
  • Berpengalaman dengan tools testing (Jest, Cypress, atau RTL)
  • Mampu menulis kode yang reusable, maintainable, dan well-tested
  • Nilai plus: pengalaman di industri edtech, SaaS, atau produk B2B
  • Komunikasi yang baik untuk bekerja lintas fungsi dengan desainer dan product manager

Tanggung Jawab

  • Memimpin pengembangan fitur frontend dari rancangan hingga rilis
  • Menjadi technical lead untuk keputusan arsitektur frontend
  • Berkolaborasi dengan UI/UX designer menerjemahkan design system ke komponen kode
  • Meningkatkan performa, SEO, dan aksesibilitas aplikasi web
  • Melakukan code review dan membimbing engineer lain
  • Berkontribusi pada dokumentasi teknis dan best practice internal
  • Bekerja sama dengan tim backend dalam desain API dan kontrak data

Benefit

  • Bekerja di industri edtech yang berdampak luas
  • Fleksibilitas kerja remote
  • Tim yang menjunjung tinggi craft dan engineering excellence
  • Kesempatan memimpin dan membentuk arah teknis produk
  • Akses ke tooling dan workflow pengembangan modern
