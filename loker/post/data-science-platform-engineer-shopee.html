Data Science Platform Engineer

🏢 Shopee 📍 Jakarta 💼 Full-time 💰 Rp 15-25 Juta 📅 2026-07-08
Full-time Teknologi

Shopee, platform e-commerce terdepan di Asia Tenggara, mencari Data Science Platform Engineer untuk bergabung dengan tim Business Intelligence. Posisi ini strategis dalam membangun infrastruktur data science yang scalable untuk mendukung ribuan model ML di seluruh organisasi. Kamu akan bekerja kolaboratif dengan Data Scientists, Data Engineers, dan Product Managers untuk mengembangkan platform yang mempercepat delivery model ML ke production.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3 tahun sebagai Platform Engineer, ML Engineer, atau Data Engineer
  • Mahir Python dan/atau Go untuk pengembangan backend/platform
  • Pengalaman kuat dengan Kubernetes, Docker, dan container orchestration
  • Paham MLOps: model deployment, CI/CD untuk ML, feature store, model monitoring
  • Pengalaman dengan cloud platform (AWS/GCP/Azure) dan Infrastructure as Code
  • Familiar dengan big data tools (Spark, Flink, Airflow) dan distributed systems
  • Kemampuan komunikasi baik untuk kolaborasi lintas tim teknis dan bisnis

Tanggung Jawab

  • Merancang dan membangun platform data science yang scalable dan reliable
  • Mengembangkan reusable data layers dan feature store untuk ML products
  • Membangun dan memelihara CI/CD pipeline untuk model deployment otomatis
  • Mengoptimalkan infrastruktur cloud untuk workload ML training dan inference
  • Berkolaborasi dengan Data Scientists untuk mempercepat eksperimen ke production
  • Mendokumentasikan arsitektur platform dan best practices MLOps

Benefit

  • Gaji kompetitif + bonus performa + RSU
  • BPJS Ketenagakerjaan dan Kesehatan lengkap
  • Asuransi kesehatan swasta untuk karyawan dan keluarga
  • Hybrid working arrangement (WFO/WFH fleksibel)
  • Budget pembelajaran dan sertifikasi cloud/MLOps
  • MacBook Pro dan workstation high-spec
  • Diskon karyawan Shopee dan akses platform pembelajaran internal
