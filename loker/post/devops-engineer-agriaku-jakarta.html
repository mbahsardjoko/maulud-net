DevOps Engineer

🏢 AgriAku 📍 Jakarta Metropolitan Area 💼 Full-time 💰 Rp 12-20 Juta 📅 2026-07-02
Full-time Teknologi

AgriAku, perusahaan agritech terdepan di Indonesia yang menghubungkan petani dengan pasar dan layanan keuangan, membuka lowongan untuk DevOps Engineer. Kami mencari engineer yang berpengalaman dalam mengelola infrastruktur cloud berskala besar. Kamu akan bertanggung jawab membangun dan memelihara CI/CD pipeline, mengelola container orchestration, dan memastikan sistem kami berjalan dengan reliable dan scalable. Posisi ini cocok untuk engineer yang ingin berkontribusi pada sektor pertanian digital Indonesia.

📎 Sumber: LinkedIn Indonesia

Kualifikasi

  • Minimal 2-3 tahun pengalaman sebagai DevOps Engineer atau Infrastructure Engineer
  • Pengalaman dengan cloud platforms (AWS, GCP, atau Azure)
  • Kemampuan containerization dengan Docker dan orchestration dengan Kubernetes
  • Pengalaman dengan CI/CD tools (GitLab CI, Jenkins, atau GitHub Actions)
  • Scripting skills (Bash, Python, atau Go)
  • Familiar dengan monitoring tools (Prometheus, Grafana, atau Datadog)
  • Pemahaman tentang networking dan security best practices

Tanggung Jawab

  • Merancang dan mengelola infrastruktur cloud yang scalable dan secure
  • Mengembangkan dan memelihara CI/CD pipeline untuk deployment otomatis
  • Memonitor performa sistem dan melakukan troubleshooting issue
  • Mengelola container orchestration dengan Kubernetes dan Docker
  • Berkolaborasi dengan tim engineering untuk optimasi infrastruktur
  • Mengimplementasikan automation untuk operational tasks

Benefit

  • Bergabung dengan agritech startup yang berdampak di sektor pertanian
  • Kesempatan bekerja dengan teknologi cloud terkini
  • Flexible working environment
  • Professional development opportunities
  • Kompensasi kompetitif dengan benefit tambahan
