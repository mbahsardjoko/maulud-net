Data Engineer

🏢 PT Satu Dental Indonesia 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 12-20 Juta 📅 2026-07-28
Full-time Teknologi

PT Satu Dental Indonesia, perusahaan penyedia solusi kesehatan gigi terintegrasi yang modern dan berbasis teknologi, membuka lowongan Data Engineer untuk bergabung dengan tim data analytics. Kamu akan bertanggung jawab membangun dan memelihara data pipeline, mengelola infrastruktur data, dan memastikan data berkualitas tinggi tersedia untuk analisis bisnis. Posisi ini cocok untuk data engineer yang memiliki pengalaman dengan big data technologies dan ingin berkontribusi pada transformasi digital industri kesehatan.

📎 Sumber: Jora

Kualifikasi

  • Minimal S1 di bidang Computer Science, Information Technology, atau terkait
  • Pengalaman 2+ tahun sebagai Data Engineer atau peran serupa
  • Mahir dalam SQL dan Python untuk data processing
  • Pengalaman dengan ETL/ELT pipeline dan tools (Airflow, dbt, Apache Spark)
  • Familiar dengan cloud data platforms (BigQuery, Redshift, Snowflake)
  • Pengalaman dengan database relasional (PostgreSQL, MySQL) dan NoSQL (MongoDB)
  • Pemahaman tentang data warehousing dan data modeling
  • Pengalaman dengan version control (Git) dan CI/CD
  • Kemampuan analitis dan problem-solving yang kuat
  • Bersedia bekerja full-time di Jakarta

Tanggung Jawab

  • Merancang, membangun, dan memelihara data pipelines yang scalable
  • Mengelola dan mengoptimalkan data warehouse untuk performa query
  • Melakukan data integration dari berbagai sumber (API, database, file)
  • Memastikan data quality, consistency, dan reliability
  • Berkolaborasi dengan data analyst dan data scientist untuk kebutuhan data
  • Mengimplementasikan monitoring dan alerting untuk data infrastructure
  • Mendokumentasikan data architecture dan pipeline documentation
  • Melakukan performance tuning dan cost optimization pada cloud data platforms

Benefit

  • Asuransi kesehatan tambahan
  • Laptop high-spec disediakan
