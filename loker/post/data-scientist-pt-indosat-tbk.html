Full-time Teknologi

PT. Indosat Tbk, operator telekomunikasi terkemuka di Indonesia, membuka posisi Data Scientist untuk bergabung dengan tim data dan AI mereka. Kamu akan mentransformasi dataset kompleks menjadi insight actionable yang mendorong keputusan bisnis strategis. Posisi ini cocok untuk data scientist yang memiliki pengalaman dengan data mining, feature engineering, dan machine learning pada data skala besar, serta ingin berdampak pada jutaan pelanggan Indosat.
