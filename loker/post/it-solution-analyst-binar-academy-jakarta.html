IT Solution Analyst

🏢 Binar Academy 📍 Jakarta 💼 Full-time 💰 Rp 12-20 Juta 📅 2026-07-17
Full-time Teknologi

Binar Academy, edtech platform terkemuka di Indonesia yang menyediakan bootcamp programming dan karir tech, mencari IT Solution Analyst untuk tim Product & Technology mereka di Jakarta. Kamu akan berperan sebagai jembatan antara business stakeholder dan engineering team: menganalisis kebutuhan, mendesain solusi teknis, menulis functional specification, dan memastikan delivery produk edtech (LMS, mobile app, career platform) yang berkualitas. Posisi ini cocok untuk BA/SA yang punya passion pada education technology dan ingin impact ke ribuan learner Indonesia.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3 tahun sebagai Solution Analyst / Business Analyst / System Analyst / Product Analyst
  • Kemampuan analisis kuat: requirement gathering, process modeling (BPMN, UML), gap analysis
  • Mahir menulis functional specification, user stories, acceptance criteria (Gherkin/BDD)
  • Paham SDLC: Agile/Scrum, Jira, Confluence, Figma (untuk review design)
  • Familiar dengan teknologi modern: REST API, microservices, database, mobile/web architecture
  • Kemampuan SQL untuk query data sendiri (tidak bergantung analyst full-time)
  • Komunikasi stakeholder management excellent (technical & non-technical)
  • Background Computer Science / Information Systems / Engineering - nilai plus
  • Passion pada education technology, edtech, lifelong learning

Tanggung Jawab

  • Menganalisis kebutuhan bisnis dari Product, Marketing, Operations, Career Team untuk solusi teknis
  • Mendesain solution architecture, data flow, system integration untuk fitur-fitur baru platform Binar
  • Menulis PRD, functional spec, user stories, acceptance criteria yang siap untuk development
  • Berkolaborasi dengan Engineering (Backend, Frontend, Mobile), UX/UI, QA untuk delivery
  • Melakukan user research, data analysis, competitive analysis untuk opportunity identification
  • Mengelola product backlog: prioritization berbasis data (RICE/WSJF), dependency mapping
  • Memvalidasi implementasi: UAT, test case review, demo ke stakeholder
  • Mendokumentasikan system design, API contract, data dictionary untuk knowledge sharing

Benefit

  • Gaji kompetitif Rp 12-20 Juta/bulan + performance bonus
  • BPJS Kesehatan, Ketenagakerjaan, Asuransi Jiwa
  • Hybrid work: fleksibel WFO/WFH sesuai kebutuhan proyek
  • Laptop high-spec disediakan (MacBook/Windows high-end)
  • Budget learning: kursus tech, sertifikasi, konferensi, buku
  • Akses gratis ke semua kursus Binar Academy (Full Stack, Data Science, UI/UX, dll)
  • Makan siang & snack, coffee bar di kantor
  • Cuti tahunan 12+ hari, parental leave, wellness program
  • Impact nyata: membantu ribuan learner Indonesia bangun karir tech
