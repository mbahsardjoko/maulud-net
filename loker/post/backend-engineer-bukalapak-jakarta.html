Software Development Engineer, Backend

🏢 Bukalapak 📍 Jakarta, Indonesia 💼 Full-time 💰 Rp 15-28 Juta 📅 2026-07-20
Full-time Teknologi

Bukalapak, salah satu marketplace dan fintech terkemuka di Indonesia, membuka lowongan Software Development Engineer (Backend) untuk bergabung dengan tim engineering mereka. Kamu akan bertanggung jawab mendesain, mengembangkan, dan memelihara layanan backend yang scalable dan reliable untuk mendukung jutaan transaksi harian. Posisi ini cocok untuk backend engineer yang ingin berkarier di perusahaan tech skala besar dengan tantangan teknis yang kompleks.

📎 Sumber: LinkedIn

Kualifikasi

  • Minimal 2-4 tahun pengalaman sebagai Backend Engineer
  • Mahir dalam satu atau lebih bahasa: Go, Java, Python, atau Node.js
  • Pengalaman dengan relational databases (PostgreSQL, MySQL) dan NoSQL (Redis, MongoDB)
  • Familiar dengan microservices architecture, RESTful APIs, dan gRPC
  • Pengalaman dengan message queues (Kafka, RabbitMQ) dan event-driven systems
  • Paham distributed systems concepts (consistency, availability, partitioning)
  • Experience dengan containerization (Docker) dan orchestration (Kubernetes)
  • Strong debugging dan performance optimization skills

Tanggung Jawab

  • Mendesain dan mengimplementasikan backend services untuk fitur-fitur marketplace dan fintech
  • Membangun dan memelihara APIs yang scalable, secure, dan well-documented
  • Mengoptimalkan database queries, caching strategies, dan system performance
  • Melakukan code review dan mentoring junior engineers
  • Berpartisipasi dalam architecture review dan technical decision making
  • Mengimplementasikan observability (logging, metrics, tracing) untuk production systems
  • Berkolaborasi dengan frontend, mobile, dan product teams untuk delivery end-to-end

Benefit

  • Gaji kompetitif + annual bonus + performance bonus
  • BPJS Kesehatan dan Ketenagakerjaan lengkap
  • Asuransi kesehatan premium (karyawan + keluarga)
  • ESOP / stock options program
  • Flexible hybrid work arrangement
  • Annual learning budget + certification support
  • MacBook Pro / high-spec laptop disediakan
  • Makan siang gratis, snack bar, dan game room di kantor
