Full Stack Developer (WFO Bandung)

🏢 PT Infokes Indonesia 📍 Bandung, Jawa Barat, Indonesia 💼 Full-time 💰 Rp 8-15 Juta 📅 2026-07-24
Full-time Teknologi

PT Infokes Indonesia, perusahaan teknologi yang fokus pada pengembangan solusi informasi kesehatan dan sistem rumah sakit digital, membuka lowongan Full Stack Developer dengan penempatan WFO di Bandung. Kamu akan bergabung dengan tim pengembangan yang membangun platform rumah sakit terintegrasi (Hospital Information System), aplikasi pasien, dan dashboard manajemen medis. Posisi ini menawarkan kesempatan unik untuk bekerja pada health-tech yang berdampak nyata pada efisiensi layanan kesehatan di Indonesia, dengan lingkungan kerja di kota Bandung yang nyaman dan biaya hidup lebih terjangkau.

📎 Sumber: Kalibrr

Kualifikasi

  • Minimal 2 tahun pengalaman sebagai Full Stack Developer
  • Mahir dalam PHP (Laravel) atau Node.js untuk backend
  • Mahir dalam Vue.js atau React.js untuk frontend
  • Pemahaman kuat tentang database (MySQL, PostgreSQL) dan query optimization
  • Pengalaman dengan RESTful API design dan integrasi third-party (BPJS, lab, pharmacy)
  • Familiar dengan Git, Docker, dan deployment ke server Linux
  • Paham konsep keamanan data medis (HIPAA-equivalent, enkripsi, audit trail)
  • Kemampuan troubleshooting dan debugging yang cepat
  • Bersedia bekerja WFO di Bandung, Jawa Barat

Tanggung Jawab

  • Mengembangkan fitur-fitur baru untuk Hospital Information System (HIS)
  • Membangun dan memelihara RESTful API untuk frontend dan integrasi eksternal
  • Mengembangkan antarmuka pengguna untuk modul rawat jalan, rawat inap, farmasi, lab, dan billing
  • Melakukan optimasi performa database dan query kompleks
  • Berkolaborasi dengan tim QA, product owner, dan stakeholder rumah sakit
  • Mengimplementasikan standar keamanan dan privasi data pasien
  • Berpartisipasi dalam code review, sprint planning, dan retrospective
  • Mendokumentasikan arsitektur sistem, API spec, dan database schema

Benefit

  • Gaji kompetitif sesuai pengalaman (Bandung standard)
  • BPJS Kesehatan dan Ketenagakerjaan
  • Asuransi kesehatan tambahan
  • Tunjangan transportasi dan makan
  • Laptop kerja disediakan
  • Budget pelatihan dan sertifikasi (health-tech, cloud, security)
  • Lingkungan kerja kolaboratif dengan tim medis dan teknis
  • Kesempatan berkontribusi pada digitalisasi kesehatan Indonesia
  • Work-life balance yang baik di kota Bandung
