Quality Assurance Engineer

🏢 VocaGame 🌐 Indonesia (Remote/Hybrid) 💼 Full-time 💰 Rp 8-14 Juta 📅 2026-09-03
Full-time Teknologi

VocaGame, perusahaan teknologi terkemuka di Asia Tenggara yang fokus pada solusi channel dan platform inovatif untuk industri hiburan dan media, membuka lowongan Quality Assurance Engineer untuk memastikan kualitas software products mereka sebelum release ke pasar. Sebagai QA Engineer, Anda akan berperan kritis dalam software development lifecycle dengan melakukan manual dan automation testing untuk aplikasi mobile dan web platform. Anda akan bekerja sama dengan developers dan product managers untuk identify bugs, verify fixes, dan maintain quality standards yang tinggi. Posisi ini ideal untuk QA professional yang ingin berkontribusi di perusahaan tech dengan jangkauan regional.

  • Knowledge dalam API testing dan database validation
  • Strong attention to detail dan analytical problem-solving skills

  • Identify, document, dan track bugs menggunakan bug tracking tools

  • Conduct regression testing setelah bug fixes dan new releases
  • Participate dalam code review sessions dan provide QA perspective
  • Create dan maintain test documentation dan quality reports
  • Support continuous integration/continuous deployment (CI/CD) processes
