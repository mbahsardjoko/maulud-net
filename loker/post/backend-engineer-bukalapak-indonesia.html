Backend Engineer

🏢 Bukalapak 📍 Jakarta 💼 Full-time 💰 Rp 15-25 Juta 📅 2026-07-15
Full-time Teknologi

Bukalapak, pionir e-commerce Indonesia yang kini berkembang ke digital financial services (BukaFinancial) dan B2B marketplace (BukaMitra), mencari Backend Engineer untuk tim Platform Engineering. Kamu akan membangun microservices yang menangani jutaan request/hari: katalog produk, order management, payment gateway, logistics orchestration, merchant financing. Stack utama: Go, gRPC, Kafka, PostgreSQL, Redis, Kubernetes, dengan arsitektur event-driven dan DDD.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 3 tahun Backend Engineer / Software Engineer
  • Mahir Go (Golang) production-grade: concurrency, profiling, testing
  • Pengalaman mendalam microservices: service discovery, circuit breaker, distributed tracing
  • Paham database design: PostgreSQL (ACID, indexing, partitioning), Redis (caching, pub/sub)
  • Pengalaman message broker: Kafka (exactly-once, partitioning, consumer groups)
  • Familiar dengan Kubernetes: deployment, HPA, configmap, secret, operator pattern
  • Paham observability: Prometheus metrics, Loki logs, Tempo traces, alerting
  • Background Computer Science / setara, paham algoritma & struktur data

  • Mengoptimalkan latency & throughput: profiling, query tuning, caching strategy
  • Membangun platform internal: API gateway, service mesh, feature flag, rate limiter
  • Melakukan code review, design doc review, postmortem incident production
  • Berkolaborasi dengan Data Engineer untuk event streaming & data warehouse
  • Mentoring junior engineer, menjaga engineering standard (clean code, testing)
  • Berpartisipasi on-call rotation, incident response, capacity planning

  • MacBook Pro M-series + dual monitor + mechanical keyboard
  • Budget learning: GopherCon, KubeCon, course, certification, buku
  • Makan siang gratis, snack unlimited, kopi premium
