Quality Assurance Engineer

🏢 OttoDigital Group 📍 Jakarta 💼 Full-time 💰 Rp 10-18 Juta 📅 2026-07-17
Full-time Teknologi

OttoDigital Group, perusahaan teknologi finansial (fintech) yang menyediakan solusi pinjaman digital dan layanan keuangan, mencari Quality Assurance Engineer untuk tim QA mereka di Jakarta. Kamu akan mendesain test cases berdasarkan functional dan non-functional requirements, melakukan manual maupun automation testing, dan memastikan kualitas rilis produk fintech yang melayani jutaan pengguna. Posisi ini cocok untuk QA engineer yang ingin mendalami testing di domain financial services dengan regulasi ketat dan skala tinggi.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 2-3 tahun sebagai QA Engineer / Software Tester
  • Mahir mendesain test cases: functional, regression, integration, API
  • Pengalaman test automation: Selenium, Cypress, Playwright, atau Appium
  • Mahir API testing tools: Postman, RestAssured, atau pytest
  • Paham database: SQL query untuk test data preparation & validation
  • Familiar dengan CI/CD integration untuk automated testing
  • Pengalaman domain fintech/banking/e-wallet adalah nilai plus besar
  • Kemampuan analisis defect, root cause analysis, dan reporting

Tanggung Jawab

  • Mendesain test plan dan test cases untuk fitur-fitur baru produk fintech
  • Melakukan manual testing: functional, UI/UX, regression, UAT
  • Mengembangkan dan memelihara automation test suite (API, UI, Mobile)
  • Mengintegrasikan automated test ke CI/CD pipeline
  • Melakukan API testing dan contract testing untuk microservices
  • Berkolaborasi dengan Developer untuk shift-left testing
  • Menganalisis defect, RCA, dan memverifikasi bug fixes
  • Membuat test report, metrics: defect density, test coverage, release readiness

Benefit

  • Gaji kompetitif Rp 10-18 Juta/bulan + performance bonus
  • BPJS Kesehatan, Ketenagakerjaan, Asuransi Jiwa
  • Hybrid work: fleksibel WFO/WFH sesuai kebutuhan proyek
  • Laptop high-spec disediakan (MacBook/Windows)
  • Budget learning: sertifikasi ISTQB, conference, course, tools
  • Exposure testing fintech regulated, high-scale, security-focused
  • Makan siang & snack, coffee bar di kantor
  • Cuti tahunan 12+ hari, parental leave, wellness program
