Senior Software Engineer

🏢 OVO (PT Visionet Internasional) 📍 Jakarta Selatan 💼 Full-time 💰 Rp 20-35 Juta 📅 2026-07-08
Full-time Teknologi

OVO, platform pembayaran dan layanan keuangan digital terkemuka di Indonesia, mencari Senior Software Engineer untuk bergabung dengan tim engineering mereka. Posisi ini tantangan: kamu akan membangun sistem payment high-throughput, low-latency yang melayani jutaan transaksi harian. Kamu akan bekerja dengan teknologi modern (Go, Java, Kubernetes) di lingkungan yang mengutamakan engineering excellence, code quality, dan system reliability.

📎 Sumber: LinkedIn

Kualifikasi

  • Pengalaman minimal 5 tahun sebagai Software Engineer / Backend Engineer
  • Mahir Go dan/atau Java untuk pengembangan sistem high-scale
  • Pengalaman mendalam dengan distributed systems, microservices, event-driven architecture
  • Paham database design (SQL/NoSQL), caching strategy, message queue (Kafka)
  • Pengalaman production dengan Kubernetes, Docker, CI/CD, observability (Prometheus/Grafana)
  • Strong understanding of payment systems, transaction integrity, idempotency adalah nilai plus besar
  • Kemampuan mentoring junior engineer dan lead technical discussion

Tanggung Jawab

  • Merancang, mengembangkan, dan memelihara layanan payment core (top-up, transfer, payment, withdrawal)
  • Memastikan system reliability: high availability, fault tolerance, data consistency
  • Mengoptimalkan performa sistem untuk handle peak traffic (jutaan TPS)
  • Berkolaborasi dengan Security, Compliance, dan Risk team untuk payment security
  • Mentoring engineer junior, code review, dan drive engineering best practices
  • Berpartisipasi dalam architecture review, RFC, dan technology selection

Benefit

  • Gaji kompetitif + bonus performa + RSU
  • BPJS Ketenagakerjaan dan Kesehatan lengkap
  • Asuransi kesehatan premium untuk karyawan dan keluarga
  • Flexible hybrid work arrangement
  • MacBook Pro M-series + monitor eksternal + budget WFH
  • Budget pembelajaran tidak terbatas (kursus, sertifikasi, konferensi internasional)
  • Program wellness dan work-life balance
  • Akses ke produk OVO dan mitra keuangan dengan benefit eksklusif
