⭐ Frontend Developer

🏢 BRIK 📍 Jakarta 💼 Full-time 💰 Rp 8-15 Juta 📅 2026-07-14
Full-time Teknologi

BRIK, sebuah startup teknologi di Jakarta yang fokus membangun platform digital untuk industri properti, sedang mencari Frontend Developer untuk bergabung dengan tim produk mereka. Perusahaan ini percaya bahwa teknologi bisa mengubah cara orang membeli dan menjual properti di Indonesia. Kamu akan berperan penting dalam merancang dan membangun antarmuka web yang responsif, intuitif, dan performa tinggi untuk jutaan pengguna. Tim frontend mereka menggunakan React.js dengan arsitektur modern seperti component-based design dan state management. Lingkungan kerja startup yang agil dengan peluang tumbuh pesat bersama produk yang terus berkembang.

  • Pengalaman minimal 2 tahun sebagai Frontend Developer atau peran serupa
  • Mahir menggunakan React.js (Hooks, Context API, dan modern patterns)
  • Kuasai HTML5, CSS3, dan JavaScript ES6+ dengan sangat baik
  • Paham konsep responsive design, cross-browser compatibility, dan web accessibility
  • Familiar dengan tools seperti Webpack, Vite, atau bundler modern lainnya
  • Pengalaman menggunakan version control Git dan workflow branching
  • Memahami RESTful API integration dan asynchronous data fetching
  • Mampu bekerja dalam tim agile dengan komunikasi yang efektif

  • Berkolaborasi dengan UI/UX designer untuk mengimplementasikan desain pixel-perfect
  • Optimasi performa frontend termasuk loading time dan rendering
  • Melakukan code review dan menulis kode yang bersih serta terdokumentasi
  • Mengintegrasikan API backend ke dalam komponen frontend
  • Menulis unit test dan integration test untuk memastikan kualitas kode
  • Berpartisipasi dalam sprint planning dan stand-up meeting tim
